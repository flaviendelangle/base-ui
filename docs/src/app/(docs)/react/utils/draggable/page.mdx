## Usage guidelines

- **Use drag and drop for spatial interactions:** It works well for reordering lists, moving items between regions, and positioning items on a surface.
- **Treat drag and drop as a progressive enhancement:** Draggable is pointer-only. Before adding it, ensure the UI is already fully accessible via keyboard, simple controls, and workflows that do not depend on drag and drop—for example, provide a sort button in a table column header.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Draggable } from '@base-ui/react/draggable';

<Draggable.Provider>
  <Draggable.Root>
    <Draggable.Handle />
    <Draggable.Preview />
  </Draggable.Root>

  <Draggable.Target />
  <Draggable.Viewport />
</Draggable.Provider>;
```

## Examples

### Drag handle

Use `Draggable.Handle` when only part of the draggable should initiate the drag, so the rest of the component remains available for buttons, links, and other interactive content.

### Activation

Configure when a pointer gesture becomes a drag using distance, press-and-hold, immediate, or double-click activation. Pass multiple methods in the `activation` array. Double-click activation is opt-in.

<DemoActivation />

### With payload

Use a typed kind when the drop handler needs data from the dragged item. The
drop event also includes `location.grabOffset`, the point where the pointer was
pressed inside the draggable. This is useful when the dropped item's position
should not match the pointer position.

```tsx
type Card = { id: string };
const card = Draggable.createKind<Card>('card');

<Draggable.Provider>
  <Draggable.Root kind={card} payload={cardData} />
  <Draggable.Target
    accept={card}
    onDraggableDrop={({ source, location }) => {
      const { clientX, clientY } = location.current.input;
      const { x, y } = location.grabOffset ?? { x: 0, y: 0 };
      save({
        id: source.payload.id,
        x: clientX - x,
        y: clientY - y,
      });
    }}
  />
</Draggable.Provider>;
```

## useDragDropManager

Provides the imperative drag-and-drop manager for custom integrations and
non-React elements. The manager is shared by every `Draggable.Provider` on the
page.

<TypesDraggable.useDragDropManager hideDescription />

### `registerDraggable` method

Registers an existing element as a draggable. Call the returned cleanup
function when the element is removed.

```tsx
const unregister = manager.registerDraggable(element, () => ({
  kind,
  payload: card,
}));
```

### `registerDropTarget` method

Registers an existing element as a drop target. Pass the kinds it accepts and
handle drops through `onDraggableDrop`.

```tsx
const unregister = manager.registerDropTarget(element, () => ({
  accept: kind,
  onDraggableDrop: ({ source }) => save(source.payload),
}));
```

### `registerMonitor` method

Observes matching drags without rendering a component. Use it for shared UI,
analytics, or coordinating state across several drop targets.

```tsx
const unregister = manager.registerMonitor(() => ({
  accept: kind,
  onMoveStart: ({ source }) => setActive(source.payload),
  onMoveEnd: () => setActive(null),
}));
```

### `registerAutoScroller` method

Registers an existing element as an auto-scroll region when a
`Draggable.Viewport` cannot be used directly.

```tsx
const unregister = manager.registerAutoScroller(element, () => ({
  accept: kind,
  onDragScroll: (event, { x, y }) => {
    panCanvas(x, y);
    event.stopPropagation();
  },
}));
```

### `cancelDrag` method

Cancels the active drag, if any.

```tsx
manager.cancelDrag();
```
